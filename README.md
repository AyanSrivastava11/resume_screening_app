# resume_screening_app
# How too read/run this project
1. Main file is Resume Categorization Using Python.ipynb
2. Dataset - Resume.csv
3. Put dataset inside ur google drive and using google colab mount feature connect it with ur codespace
4. Then run the code inside main file and you get the same result as it follows.
5. Next - App.py is where our code is connected with front-end using Streamlit and model.pkl file for model output generation and tfidf.pkl file encoding method.
